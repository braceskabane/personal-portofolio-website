# CV Download Information

Untuk menambahkan CV yang bisa didownload, Anda perlu:

1. **Siapkan file CV Anda** dalam format PDF dengan nama: `resume-daffa-fisabilillah.pdf`

2. **Letakkan file CV di folder ini**: `/public/resume-daffa-fisabilillah.pdf`

3. **File CV akan dapat diakses melalui URL**: `https://dav-portofolio.vercel.app/resume-daffa-fisabilillah.pdf`

## Lokasi yang benar:
```
frontend-dev/
├── public/
│   ├── favicon.ico
│   ├── images/
│   └── resume-daffa-fisabilillah.pdf  ← Letakkan CV Anda di sini
```

## Tombol Download CV sudah siap di:
- HeroSection: Tombol "Download CV" dengan icon download
- ContactSection: Akan otomatis menggunakan link dari personalInfo.resume

File ini akan diabaikan oleh git (.gitignore) karena berisi informasi pribadi.
Anda bisa mengganti file ini dengan CV asli Anda.
