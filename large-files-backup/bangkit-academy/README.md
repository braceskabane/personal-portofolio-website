# Bangkit Academy 2024 - Mobile Development Learning Path

## Program Overview
Bangkit Academy adalah program career readiness yang diselenggarakan oleh Google, GoTo, dan Traveloka untuk mempersiapkan talenta digital Indonesia yang siap kerja.

## Learning Path: Mobile Development (Android)
- **Duration**: 20 weeks (February - July 2024)
- **Focus**: Android Development with Kotlin
- **Capstone Project**: Real-world application development

## Program Structure
1. **Learning Phase** (12 weeks)
   - Android fundamentals
   - Kotlin programming
   - Modern Android development
   - UI/UX design principles

2. **Capstone Project** (8 weeks)
   - Team-based development
   - Real client project
   - Cross-functional collaboration
   - Mentorship and guidance
